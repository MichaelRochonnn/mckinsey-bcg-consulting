# Consulting Firm Methodology Selection

## When to Use This Skill
Use this skill when:
- Selecting a consulting approach for a defined business problem
- Comparing firm styles between McKinsey and BCG
- Deciding between rapid strategic delivery vs deep implementation support
- Analyzing trade-offs between time horizon and execution rate
- Clients are evaluating which consulting methodology aligns with their organizational needs

## McKinsey Methodology (Fact-Based)

**Core Characteristics:**
- Emphasizes objective facts and evidence-based analysis
- Uses pre-determined frameworks to systematically collect and analyze data
- Fixed project timeline: typically 3 months per engagement

**Team Structure:**
- Senior Engagement Manager leads the project
- Supported by multiple young consultants
- Clear hierarchy with focused deliverables

**Delivery Model:**
- Provide the strategic answer upfront
- Present completed analysis and recommendations
- Leave implementation responsibility to the client
- Hand off strategy for client execution

**Advantages:**
- High efficiency and speed
- Clear, structured deliverables
- Objectively defensible conclusions
- Minimal client time investment during analysis

**Limitations:**
- Risk of "paper theory"—strategies that look good on paper but lack practical grounding
- Low implementation rate: typically 0% to 10% of recommendations executed
- Limited client ownership of the solution
- Minimal organizational capability building

**Best For:**
- Situations requiring quick, objective analysis
- Clear, well-defined problems
- Clients with strong internal implementation capabilities
- Time-sensitive strategic decisions

## BCG Japan Methodology (Psychology-Based)

**Core Characteristics:**
- Emphasizes client psychology and self-discovery
- Consultants integrate deeply into client organization
- Exploratory process through trial and error with client

**Engagement Timeline:**
- Long-term engagement: typically 3 years
- Ongoing relationship and support
- Adaptive to changing circumstances

**Team Structure:**
- Consultants become embedded in client operations
- Close working relationships with client teams
- Collaborative problem-solving approach

**Delivery Model:**
- Guide clients to discover answers themselves
- Reveal insights gradually through joint exploration
- Build client ownership throughout process
- Support implementation actively

**Advantages:**
- High implementation rate: up to 70% of strategies executed
- Strong client ownership and buy-in
- Builds organizational capabilities
- Strategies adapted to real-world constraints

**Limitations:**
- Slower pace and longer time commitment
- Higher resource intensity
- Less structured deliverables initially
- May not fully push client to their potential

**Best For:**
- Complex, ambiguous problems requiring cultural change
- Organizations needing implementation support
- Situations where client buy-in is critical
- Long-term transformation initiatives

## Decision Framework

### Key Trade-off
- **McKinsey Approach:** 3 months to achieve 10% implementation
- **BCG Japan Approach:** 3 years to achieve 70% implementation

### Selection Criteria

| Factor | Choose McKinsey If | Choose BCG Japan If |
|--------|-------------------|---------------------|
| **Time Horizon** | Need rapid results (3 months) | Can commit to long-term engagement (3 years) |
| **Implementation** | Strong internal execution capabilities | Need external implementation support |
| **Problem Type** | Well-defined, analytical problems | Complex, ambiguous, cultural issues |
| **Client Readiness** | Clear on what needs to be done | Need help discovering the path forward |
| **Budget** | Fixed, short-term investment | Long-term resource commitment |
| **Organizational Buy-in** | Already achieved | Need to build ownership throughout process |

### Decision Process

1. **Assess Time Constraints**
   - Is there urgency requiring 3-month delivery?
   - Can the organization commit to a 3-year engagement?

2. **Evaluate Implementation Capacity**
   - Does the client have strong internal execution capabilities?
   - Is implementation support critical for success?

3. **Define Problem Nature**
   - Is the problem clearly defined and analytical?
   - Does it involve complex organizational or cultural change?

4. **Consider Client Preferences**
   - Does the client prefer receiving a complete answer?
   - Will the client be more committed to self-discovery?

5. **Select Methodology**
   - McKinsey: Prioritize speed and facts
   - BCG Japan: Prioritize depth and implementation

## Important Note
The BCG style described refers specifically to BCG Japan under Hiroshi Hori. Global BCG practices may vary from this methodology archetype.
