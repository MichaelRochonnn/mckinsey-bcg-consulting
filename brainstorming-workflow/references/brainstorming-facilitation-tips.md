# 头脑风暴引导技巧

## 会议前准备

### 1. 确认参与者准备情况
- [ ] 所有成员已阅读基础数据文件
- [ ] 团队领导者已准备初始假设（如适用）
- [ ] 会议议程已明确

### 2. 环境准备
- 选择安静、不受打扰的会议室
- 准备白板或大张纸
- 准备便利贴和记号笔

## 会议中引导

### 开场阶段（5-10分钟）
1. 重申会议目标
2. 确认所有成员已熟悉基础数据文件
3. 如采用假设驱动，清晰陈述初始假设
4. 设定基本规则：
   - 不批评、不评判
   - 鼓励疯狂想法
   - 追求数量而非质量
   - 在他人想法基础上构建

### 讨论阶段（30-60分钟）

**假设驱动模式**：
1. 陈述假设："我认为X可能是Y的原因"
2. 征求反馈："大家怎么看？"
3. 收集支持证据
4. 收集反对证据
5. 修正或完善假设

**开放探索模式**：
1. 提出开放性问题
2. 鼓励自由发言
3. 记录所有想法
4. 后续分类整理

### 收尾阶段（10-15分钟）
1. 总结关键发现
2. 确定下一步行动
3. 分配责任
4. 设定时间节点

## 常见问题处理

### 问题1：沉默不语
**解决方案**：
- 先让最活跃的成员发言
- 使用"轮流发言"规则
- 提出具体问题而非开放性问题

### 问题2：一人主导
**解决方案**：
- 礼貌打断："谢谢你的想法，让我们听听其他人的观点"
- 使用便利贴收集想法，匿名展示
- 设定每人发言时间限制

### 问题3：偏离主题
**解决方案**：
- 温和提醒："这很有趣，但让我们回到核心问题"
- 设置"停车场"区域记录离题想法
- 定期回顾会议目标
