# 麦肯锡访谈技巧

## 何时使用

- 项目中需要获取特定信息
- 需要了解公司实际情况（阅读期刊文章、书籍和学术论文无法替代）
- 需要征求意见、集思广益
- 被访者表现出紧张或焦虑
- 需要建立信任关系获取真实信息

## 访谈对象

- 客户高管
- 生产线主管
- 供货商、顾客
- 行业专家
- 竞争对手
- 从资历最浅的初级经理到资深的高级副总裁

## 执行流程

### 阶段一：构建访谈提纲

1. **明确两个层面**
   - **层面一（问题罗列）**：明确知道要问的问题是什么，按任意顺序记录
   - **层面二（目的定义）**：明确从访谈中真正需要获得什么？试图达到的目的是什么？为什么要采访某人？
   - 定义访谈目的有助于将问题按顺序排好，并对其进行正确的表述

2. **问题排序策略（漏斗式结构）**
   - **起始阶段**：从一般性的问题问起（如行业概况）
   - **目的**：帮助被访者进入访谈状态，建立和谐关系
   - **禁忌**：不要一开始就扎进敏感领域（例如"你的职责是什么？"或"你在这家公司工作了多久？"）
   - **深入阶段**：在建立关系后，进行具体问题的提问

3. **聚焦核心目标（Top 3原则）**
   - 自我提问："在访谈结束时，我最想知道的3件事是什么？"
   - 这3件事就是走进办公室时要关注的焦点
   - 在离开前应竭尽全力找到答案

4. **提纲结尾**
   - 每个访谈提纲都应该以"麦肯锡原型问题"结尾
   - 在问完所有问题或剩下的时间内提出

### 阶段二：管理被访者焦虑

1. **保持敏感心态**
   - 认识到对很多人来说，接受关于工作或公司的采访是件让人紧张不安的事
   - 被访者可能担心失业
   - 采访者拥有权力和权威，必须对这种恐惧保持敏感

2. **减轻焦虑（展示利益）**
   - 向被访者证明访谈过程将如何惠及他们自身
   - 强调这是解决公司问题的过程
   - 具体利益点：假如让他们的工作更有效率，或者提高了雇主的利润率，最终都会对他们有利

3. **信息交换策略**
   - 不要害怕做交换
   - 被访者为你提供了信息；如果你掌握信息，也可以与他们分享
   - 大多数人都希望自己知道公司更多的事

4. **避免滥用权力**
   - 抵制把访谈的权力当成武器的诱惑
   - 不要把权威当成徽章一样炫耀
   - 如果炫耀权威，被访者会像警匪片中的歹徒一样"缄默不语"

5. **权威的例外使用**
   - 仅在真的遇到阻碍或敌意时，才可以将权威带到访谈中
   - 一旦阻碍和敌意结束后，必须立即将权威束之高阁
   - 伴随权力而来的是必须睿智地加以运用的责任

## 输出成果

- 填补知识空白所需的信息
- 客户经验及一线实际情况
- 建立信任关系，消除被访者防御心理
- 获取真实有效的信息

## 关键原则

- 访谈是获取实际情况的最佳方式（阅读文献无法替代）
- 访谈适用于从初级经理到高级副总裁的所有层级
- 必须聚焦3个核心目标
- 建立信任比获取信息更重要
