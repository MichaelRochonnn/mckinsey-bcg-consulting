# 可行性评估案例

## 案例背景：金融机构卫星项目

**初始方案**：
- 建议客户放弃卫星连接项目
- 改用其他技术方案
- 预期节省1.7亿美元

**可行性评估发现**：
1. 客户已投入大量资源完成一半的卫星连接项目
2. 中途更换方案带来巨大的政治风险
3. 客户管理层无法承受推翻已进行中项目的政治后果

**调整后的方案**：
- 保留卫星项目
- 寻找其他节省机会
- 聚焦更大的节省目标（5亿或10亿美元的机会）

**关键教训**：
- 即使方案有大量数据支撑、前景巨大，如果客户无法实施，该方案也是毫无用途的
- 必须考虑政治风险和客户能力边界
- 当学术理想与商业现实相撞时，后者是赢家
