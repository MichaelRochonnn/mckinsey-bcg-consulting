# Multi-Skill Workflow Compositions

Use these recipes when the user asks for an end-to-end answer rather than a single framework.

## 1. Strategy Case From Scratch

Use when: the user has a market, product, growth, or competitive strategy question.

Load in order:
1. `mckinsey-problem-solving-methodology`
2. `mckinsey-issue-tree-structuring`
3. `3c-analysis-overlap-dynamics`
4. `external-forces-analysis`
5. `impact-speed-prioritization-matrix`
6. `consulting-proposal-structures`

Output: problem statement, issue tree, key hypotheses, evidence plan, strategic options, recommendation, next-step workplan.

## 2. Executive Recommendation Memo

Use when: the user needs a concise CEO/CFO/board-ready recommendation.

Load in order:
1. `structured-problem-solving-mckinsey`
2. `key-driver-analysis`
3. `mckinsey-communication-principles`
4. `executive-communication-integrity`

Output: headline answer, rationale, decision required, risks, facts still needed, suggested executive ask.

## 3. Data-Heavy Business Analysis

Use when: the user has data, dashboards, or correlations and needs business action.

Load in order:
1. `hypothesis-driven-data-analysis`
2. `fact-based-research-mckinsey`
3. `fact-creation-methodologies`
4. `daily-knowledge-synthesis`

Output: hypotheses, causality checks, data tests, fact gaps, new-fact creation plan, decision recommendation.

## 4. Transformation Implementation

Use when: a recommendation is approved but execution, adoption, or scaling is hard.

Load in order:
1. `consulting-client-engagement`
2. `mckinsey-project-lifecycle`
3. `project-execution-management`
4. `change-management-implementation`
5. `implementation-scaling-motivation-strategy`

Output: implementation phases, governance, stakeholder ownership, change risks, operating cadence, 0-1-10-100 scaling plan.

## 5. Operations Or Manufacturing Crisis

Use when: quality, cost, delivery, defect, production, or process reliability is the main issue.

Load in order:
1. `toyota-stop-valve-protocol` if there is an active defect or safety/quality abnormality.
2. `qcd-issue-tree-production-analysis`
3. `process-standardization-for-leverage`
4. `matrix-quadrant-decision-strategy`

Output: containment actions, root-cause tree, QCD diagnosis, process standardization plan, delegation/automation decisions.

## 6. Workshop Or Brainstorming Session

Use when: the user needs to run a meeting, generate options, or align a group.

Load in order:
1. `pre-brainstorming-preparation`
2. `brainstorming-workflow`
3. `brainstorming-facilitation`
4. `team-facilitation-mckinsey`
5. `daily-knowledge-synthesis`

Output: agenda, pre-work, prompts, facilitation rules, capture template, synthesis plan.

## 7. Client Or Stakeholder Resistance

Use when: politics, passive resistance, client buy-in, or cross-functional alignment blocks progress.

Load in order:
1. `consulting-client-engagement`
2. `difficult-stakeholder-management`
3. `mckinsey-team-management`
4. `mckinsey-communication-principles`

Output: stakeholder map, resistance diagnosis, influence moves, revised communication, escalation criteria.

## 8. Proposal Or Sales Without Selling

Use when: the user needs to win trust, develop clients, or write a consulting proposal.

Load in order:
1. `non-selling-client-development` or `non-promotional-business-development`
2. `consulting-proposal-structures`
3. `mckinsey-communication-principles`
4. `project-feasibility-assessment`

Output: trust-building plan, proposal narrative, scope, deliverables, feasibility risks, next conversation.

## 9. Corporate Career Navigation

Use when: the user faces high-pressure performance expectations, organization politics, mentorship, or promotion dynamics.

Load in order:
1. `mckinsey-organization-dynamics`
2. `career-expectation-management`
3. `active-mentor-finding-management`
4. `mckinsey-professional-principles`
5. `work-life-boundary-management` when sustainability is relevant.

Output: situation diagnosis, power/expectation map, mentor moves, boundary plan, reputation risks, next actions.

## 10. Consulting Interview Or Talent Assessment

Use when: preparing for interviews or evaluating candidate potential.

Load in order:
1. `mckinsey-case-interview-strategy` for candidate preparation.
2. `mckinsey-talent-assessment` or `consultant-candidate-evaluation` for evaluator mode.
3. `structured-problem-solving-mckinsey`

Output: interview plan, case structure, scoring rubric, strengths/gaps, practice drills.
