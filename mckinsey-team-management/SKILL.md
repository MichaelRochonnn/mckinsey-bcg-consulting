# 咨询项目团队问题成员管理

## 何时使用

识别到以下情况时立即启动：
- 客户团队中存在不配合或敌意的"讨债鬼"成员
- 会议中出现牢骚鬼或煽动者干扰正常进程
- 无法将问题成员移出团队（无合适人选或可能招来新问题）
- 需要处理有政治后台的高级敌意型成员

## 问题成员类型识别

### 类型A：毫无用处型

**特征识别清单**
- [ ] 外表不修边幅（着装不搭配、有污渍等）
- [ ] 具备专业能力（对业务熟悉，和顾问一样聪明）
- [ ] 态度消极：不愿合作，认为咨询"兜售一派胡言"
- [ ] 行为表现：每天露面但顽固拒绝合作
- [ ] 被动配合：因上司指派而留在团队中

**典型案例**：汉克——身高一米九三，领带与衬衫不搭，西装有食物污渍，对所在银行区域熟悉但拒绝合作

### 类型B：敌意型/破坏者型

**特征识别清单**
- [ ] 背景光鲜（名校学历、高级职位）
- [ ] 职位关键：客户团队领导，与高管主要联系渠道
- [ ] 有政治后台：得到排斥顾问的高层派系支持
- [ ] 主动破坏行为：
  - "巧妙而积极"地阻止工作完成
  - 把团队带到死胡同
  - 在背后对管理层说坏话
  - 在做汇报时搞破坏
- [ ] 动机明确：高层不喜欢顾问建议的方向

**典型案例**：卡洛斯——阿根廷人，牛津本科，哈佛MBA，客户团队领导，有高层派系支持

### 类型C：现场干扰型（会议场景）

**特征识别**
- 牢骚鬼：持续抱怨、私下嘀咕
- 煽动者：试图引发对抗、破坏会议氛围

## 决策流程

```
能否让该成员离开团队？
├── 能 → 尽量移出团队（理想情况）
└── 不能 → 判断类型
    ├── 毫无用处型 → 避开策略
    ├── 敌意型/破坏者型 → 升级策略
    └── 现场干扰型 → 身体干预技巧
```

## 分类型管理策略

### 毫无用处型：避开与隔离

**核心策略**：避开他，给他独立工作

1. **分配独立工作**
   - 给他一块"他能独立完成的工作"
   - 工作性质：对项目不太重要，但也必须有人去做

2. **团队资源调配**
   - "依靠其他成员来训练这个懒散的家伙"
   - 不亲自投入精力，借助团队其他成员

3. **长期转化尝试（可选）**
   - "雕琢那些璞玉"——工作几周后尝试带入团队
   - 让其理解麦肯锡解决问题的方法
   - 最终目标：使其"肯为我们的解决方案效劳"

### 敌意型/破坏者型：升级至项目经理

**核心策略**：不直接对抗，依赖项目经理的政治力量

1. **快速识别**："很快意识到不是朋友"——不抱幻想，果断定性
2. **立即上报**：把问题成员留给项目经理处理
3. **依赖项目经理能力**：
   - 政治技巧和政治力量
   - 顾问本人不直接对抗，避免政治风险
4. **接受现实**："即使是这样，始终是一个眼中钉"——承认某些敌意型成员无法彻底解决，只能持续管理

### 现场干扰型：身体干预技巧

**适用场景**：会议进行中，需要立即制止干扰

1. **物理接近**
   - 让领导或主持人站在麻烦制造者旁边

2. **肢体暗示**
   - 偶尔拍拍他们的肩膀，让其知道一直被关注

3. **处理窃窃私语**
   - 如果小声嘀咕，立即介入

4. **公开化要求**
   - 让他们大声讲出来
   - 话术："为什么不让全班都听听呢？"

## 关键原则总结

| 原则 | 说明 |
|------|------|
| 优先顺序 | 离开团队 > 避开/隔离 > 转化雕琢 |
| 资源投入 | 对毫无用处型，不投入核心精力；对敌意型，不直接对抗 |
| 政治敏感性 | 敌意型成员往往有高层支持，需由有政治力量的人处理 |
| 现实预期 | 并非所有"讨债鬼"都能转化，有些只能全程管理 |
