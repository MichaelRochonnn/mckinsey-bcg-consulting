# 客户概念的广义定义与应用

本技能旨在帮助非外部咨询顾问（如企业内部员工或个人）在运用麦肯锡技巧时，通过转换视角，将当前所在的组织视为'客户'，从而更有效地解决问题。

## 适用场景

- 你不是外部咨询顾问，但需要运用麦肯锡技巧解决商业问题。
- 你正在处理企业内部问题，需要客观的第三方视角。
- 你需要为个人或所在组织制定解决方案。

## 执行步骤

### 1. 识别当前角色

判断自己是否为外部咨询顾问：
- **是**：'客户'指出现问题需要你解决的组织（通常是付费方）。
- **否**：处理内部问题时，严格意义上没有传统'客户'。

### 2. 执行思维转换

如果你不是外部咨询顾问，必须进行核心思维转换：
- **核心原则**：将'你（或者你的组织）就是你自己的客户'作为指导原则。

### 3. 应用咨询视角

将当前工作的组织视为'客户'，不论你是局外人还是局内人：
- 想象你正在为该组织提供咨询服务。
- 保持客观、中立的态度。
- 使'客户'一词适用于你工作的任何组织。

### 4. 运用技巧解决问题

基于上述视角转换，开始应用书中的相关技巧：
- 以服务'客户'的心态分析问题。
- 确保解决方案符合'客户'（即你所在组织）的最佳利益。

## 预期效果

通过这种视角转换，你将能够在非咨询场景下更得心应手地运用麦肯锡技巧，以客观、专业的态度解决面临的商业问题。
