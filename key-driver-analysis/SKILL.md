# 关键驱动因素分析

## 适用场景
- 复杂的企业问题分析
- 系统分析场景
- 多变量决策场景

**不适用**：需要极高精度且不能忽略任何微小变量的物理计算场景（除非已验证其可忽略性）

## 执行步骤

### 1. 全面罗列潜在因素
列出所有可能影响结果的因素，例如：
- 气候因素
- 客户信心
- 原材料价格
- 其他相关变量

可能存在数十甚至上百个不同因素。

### 2. 应用计算的平方律进行简化

**理解复杂度代价**：
- 根据工程师的"计算的平方律"，系统求解所需的计算量至少与方程个数的平方数增长得一样快
- 如果问题的复杂度变为原来的2倍，解决这个问题需要的时间就会变为原来的4倍

**类比参考**：
- 天文学家分析行星运动时，虽然太阳系中有数百万天体且存在引力效应，但为了分析核心问题，会忽略大部分其他天体的运动

### 3. 筛选关键驱动因素

从众多因素中识别出最重要的少数几个（例如X、Y、Z）：
- 确定哪些因素对结果起决定性作用
- 明确将其他因素归类为"无足轻重"的因素

### 4. 聚焦核心分析

- 避免将整个问题撕成一层层、一片片的小问题
- 将"完整的、以事实为基础的分析"运用于这些关键驱动因素上
- 钻研问题的核心，避免走进死胡同

## 预期收益
- 节省时间
- 节省精力
- 避免"大海捞针"式地寻找所需的所有知识

## 关键变量
- **潜在因素总数**：影响问题的所有可能因素的数量（如100个）
- **关键驱动因素**：对结果起决定性作用的少数核心因素（如X、Y、Z）
