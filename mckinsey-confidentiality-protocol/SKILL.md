# 麦肯锡保密行为规范准则

## 何时使用

当你处于以下情境时必须严格执行本规范：
- 接触客户机密信息（无论在公司内外）
- 在公共场所或交通工具中携带客户资料
- 与客户以外的人员讨论项目相关内容
- 在私人场所存放工作资料
- 需要建立或维护客户信任关系

## 核心原则

1. **保密是基本职业素养** — "如果你不能做到保密，你就不是一个称职的咨询顾问"
2. **主动判断信息披露边界** — "要知道什么时候说什么，什么时候应保持沉默"
3. **采取过度谨慎态度** — "在这方面不妨偏执一点"

## 执行流程

### 第一步：评估环境风险

| 场景 | 风险等级 | 关键检查点 |
|------|---------|-----------|
| 飞机/高铁等交通工具 | 极高 | 邻座人员身份不明，可能有竞争对手、记者或客户人员 |
| 私人住所（含他人住所） | 高 | 同住人员可能来自竞争公司或相关行业 |
| 公共场所（餐厅、咖啡厅） | 高 | 谈话可能被邻桌听到 |
| 公司办公室 | 中 | 同事可能同时为竞争客户服务 |
| 客户现场 | 中 | 需确认信息披露已获得授权 |

### 第二步：采取物理保护措施

**公文包管理**
- 任何场所过夜，公文包必须上锁
- 即使在完全私人的空间（如住所），不降低安全标准

**交通工具中的资料管理**
- 绝对禁止在飞机上取出客户资料
- 原因："我们永远不知道是谁坐在旁边——竞争对手、记者，或者是客户公司的某个人"
- 风险后果：客户人员发现顾问在公共交通中处理其公司资料，将造成严重信任危机

### 第三步：控制言语信息

**办公室外部**
- 绝对禁止提及客户真实名称

**办公室内部**
- 即使公司内部，有时也不提客户名字
- 原因：可能同时为同一产业的不同客户服务，同事之间存在利益冲突
- 解决方案：使用代号（code）替代真实客户名称
- 注意：代号系统存在泄露风险，需谨慎使用

### 第四步：建立保密条件反射

- 将保密意识内化为日常行为习惯
- 在任何情境下自动执行保密判断
- 持续保持警惕，不因场景熟悉而放松

## 关键决策检查清单

在以下动作前强制检查：
- [ ] 打开公文包前：当前环境是否安全？
- [ ] 讨论项目前：听众是否具备知情权限？
- [ ] 提及客户前：是否使用了代号？
- [ ] 存放资料前：物理空间是否可控？

## 失败警示

**德国项目经理案例**：回家发现女友（另一家咨询公司）留下的便条提及"代码A公司的晚宴"
- 问题：女友如何得知代码对应的真实客户？
- 教训：代号系统存在信息泄露风险，行业间信息交叉可能导致保密失效
