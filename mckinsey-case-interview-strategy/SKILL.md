# 麦肯锡案例面试应对策略

## 何时使用

- 面试官提出商业案例问题（如"某企业利润下滑，分析原因"）
- 面试官提出估算/费米问题（如"美国有多少加油站"）
- 面试官抛出大量信息，需要快速结构化分析

## 核心原则

面试官的核心目的：**观察你如何思考，而非你是否答对**。商业问题通常没有唯一标准答案。

## 应对框架：三步法

### 第一步：分解问题
- 将大问题拆解为可处理的小问题
- 建立清晰的分析框架（MECE原则）
- 避免试图一次性解决全部问题

### 第二步：提出关键问题
- 向面试官询问必要信息
- 通过提问展示思路方向
- 确认理解问题的边界和假设

### 第三步：建立合理假设
- 在数据缺失时，基于常识和逻辑进行估算
- 明确说明假设依据
- 展示数字敏感度

## 案例类型识别

| 类型 | 特征 | 应对重点 |
|------|------|---------|
| 一般案例 | 麦肯锡真实案例的紧凑版 | 结构化分析框架 |
| 开放式案例 | 边界模糊、信息杂乱 | 主动定义问题范围 |
| 费米问题 | 稀奇古怪的估算题 | 展示分解逻辑和假设链条 |

## 信息流管理

当面试官抛出大量信息时：
1. 保持冷静，不被信息淹没
2. 识别关键变量，忽略干扰项
3. 展示"越挖越深"的探究能力
4. 适时总结已获信息，确认理解

## 执行检查清单

- [ ] 是否建立了清晰的分析框架？
- [ ] 是否主动提出了关键问题？
- [ ] 假设是否有逻辑依据？
- [ ] 是否在信息过载时保持了结构化思维？
- [ ] 是否展示了思考过程而非仅给出答案？

## 常见陷阱

- **追求唯一正确答案**：麦肯锡案例重在过程，结论可合理多样
- **沉默计算**：边思考边出声，让面试官跟上你的思路
- **跳过假设说明**：每个估算数字都要解释来源
- **被动等待信息**：主动索取需要的数据，展示掌控力
