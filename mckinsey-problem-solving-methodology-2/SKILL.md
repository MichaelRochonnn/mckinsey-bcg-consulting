# 麦肯锡问题解决方法论

## 使用时机
当面临以下情况时应用此技能：
- 需要解决复杂的商业问题
- 需要将大问题分解为可管理的子问题
- 需要形成清晰、完整的分析框架
- 需要制定基于事实的解决方案

## 核心原则

### 1. MECE原则（相互独立、完全穷尽）

**定义**：MECE发音为"me-see"，全称为Mutually Exclusive, Collectively Exhaustive

**应用要求**：
- **相互独立**：每个问题/条目必须独立、不同，彼此之间无重叠
- **完全穷尽**：清单必须囊括一切与问题相关的条目，解决所有子问题即解决母问题

**应用场景**：
- 问题分解的第一层结构
- 每份文件、演示文稿、电子邮件和语音留言
- 将"大的复杂的问题"拆分成"小的容易解决的子问题"

### 2. 假设驱动方法

**核心循环**：
```
大胆假设 → 小心求证 → 验证结果 → 调整假设
```

**执行要点**：
- 必须重复强调："大胆假设，小心求证"
- 假设作为讨论起点，而非最终结论
- 通过事实验证或证伪假设

### 3. 事实与严格分析

**执行标准**：
- 遵循"严格的信息标准和分析标准"
- 对每个议题进行"求证与再求证"
- 保持"高水准的交流"

### 4. 系统化思维

**核心口诀**："系统、系统、系统"

**执行步骤**：
1. 运用MECE原则分解问题
2. 建立假设
3. 收集事实验证假设
4. 形成解决方案

## 执行流程

### 步骤1：问题定义
- 明确需要解决的核心问题
- 确认问题边界和范围

### 步骤2：MECE分解
- 将问题分解为相互独立、完全穷尽的子问题
- 确保第一层结构清晰完整

### 步骤3：形成假设
- 基于初步理解提出假设
- 假设应具体、可验证

### 步骤4：事实验证
- 收集相关数据和信息
- 严格验证每个假设
- 记录数据来源

### 步骤5：综合结论
- 基于验证结果形成结论
- 确保逻辑链条完整

## 关键变量

- **事实**：用于分析的基础信息，需经过严格验证
- **假设**：待验证的初步判断，需大胆提出
- **MECE**：相互独立、完全穷尽的分析原则

## 输出成果

形成既相互独立（无重叠）又完全穷尽（无遗漏）的问题分解结构，确保逻辑清晰和思维严谨，最终实现基于事实的解决方案。
