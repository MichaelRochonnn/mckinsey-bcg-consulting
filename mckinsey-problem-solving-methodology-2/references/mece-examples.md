# MECE原则详细示例

## 正确示例

### 问题：如何提高公司利润？

**MECE分解**：
1. 增加收入
   - 提高价格
   - 增加销量
   - 开拓新市场
2. 降低成本
   - 降低生产成本
   - 降低运营成本
   - 降低管理成本

### 问题：客户满意度下降的原因？

**MECE分解**：
1. 产品问题
   - 质量缺陷
   - 功能不足
   - 设计缺陷
2. 服务问题
   - 响应速度慢
   - 服务态度差
   - 专业度不足
3. 价格问题
   - 价格过高
   - 价值不匹配

## 错误示例

### 问题：如何提高公司利润？

**非MECE分解**：
1. 提高价格
2. 增加销量
3. 提高产品质量
4. 降低生产成本
5. 改善客户服务

**问题**：
- "提高产品质量"和"改善客户服务"可能重叠（服务也是质量的一部分）
- 没有穷尽所有可能性（如开拓新市场、降低运营成本等）

## MECE检查清单

- [ ] 每个子问题是否独立？
- [ ] 是否有重叠？
- [ ] 是否有遗漏？
- [ ] 所有子问题加起来是否等于母问题？
- [ ] 是否便于后续分析？
